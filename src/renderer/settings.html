Docker Sandboxes

Name or full path of the Docker Sandboxes CLI. Leave it as sbx if it is on your PATH.
A shell command that is run inside the sandbox to get the launch token of the web UI. It must print token=… or a URL containing it; {port} is replaced by the port published on this computer. With a command set, the Sandboxes dialog offers “Login” next to “Connect”. Example, when the web UI logs its URL to a file: grep -o 'token=[A-Za-z0-9_-]*' ~/dsh-web.log | tail -1

Logging

How much the app writes to its own log file. Changes apply at once.
Replaces token=… in sandbox logs shown by the log viewer. Anyone who can use the sandbox can read the files directly, so this only guards against shoulder surfing and accidental screenshots. The app's own log never contains tokens.
